# Thermite

Thermite is our custom C++20 game engine that uses the **Graphite** renderer for a Year 3 team project at **Breda University of Applied Sciences**.

## Tech Stack (WIP)
- Modern C++20 architecture
- Graphite renderer
- CMake (project configuration)

## Getting Started (WIP)
```bash
git clone https://github.com/<org-or-user>/thermite.git
cd thermite
cmake -S . -B build
cmake --build build
```
